<br>

## 🎯 목표

- 암기 중심 학습이 아닌, **동작 원리와 문제 맥락까지 깊이 이해**합니다.
- 학습 내용을 논리적으로 **설명하는 능력을 강화**합니다.
- 문제 해결 관점에서 **사고**하고 토론합니다.
- 학습과 토론의 결과를 **구조화된 기록으로 축적**합니다.
- 단기 집중이 아닌 **유지 가능한 학습 리듬을 구축**합니다.
